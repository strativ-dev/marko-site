The workflow

How it works, exactly.

The full workflow, step by step. No magic, no hand-waving.

1

Sign up once

  • Install the extension, click the toolbar icon, hit Get started.
  • Sign up on the web with email and password. The extension picks up your session automatically; no copying tokens.
  • From then on the extension and the web app share one account.

2

Create a project for a site

  • Open the site you're reviewing and click the Marko icon.
  • If a project already exists for that site, Marko shows it with its active and resolved counts.
  • Otherwise one click on Create project for this page starts one and drops you straight into review mode.

3

Pin comments on the live page

  • In comment mode the element under your cursor is outlined, so you see exactly what a pin will attach to.
  • Click it, write the comment, set a severity, mention teammates with @.
  • Marko captures a cropped screenshot of that element and anchors the pin so it survives scrolling and resizing.

Discuss and resolve in place

Track it on the board

Built in

Everything a review needs, nothing you don't.

One extension replaces screenshot tools, spreadsheets, and endless email threads.

Element-anchored pins

Pins lock onto page elements and stay put through scrolling, resizing, and reloads.

Threads & mentions

Comment threads with @mentions, image attachments, and resolve states.

Annotated screenshots

Arrows, boxes, pen, text, and a px ruler, captured with OS, browser, and viewport metadata.

Kanban triage

Drag reports between severity columns. Filter by status, device, assignee, and due date.

Design inspectors

Element, typography, and color inspectors with one-click copy CSS and selector.

Private by default

Projects are visible only to their members; pin screenshots are access-controlled so nobody outside the team can load them.

Get started

Installed in two minutes.

Marko ships as an open-source extension for Chrome and Firefox.

Download for Chrome
1

Unzip the downloaded file.

2

Open chrome://extensions in Chrome.

Paste it into the address bar — Chrome blocks direct links to it.

3

Turn on Developer mode (top-right toggle).

4

Click Load unpacked and select the unzipped folder.

5

Pin Marko to your toolbar, open any site, press Alt+M (⌘⇧M on Mac). Done.

Download for Firefox
1

Open about:debugging in Firefox.

2

Click This Firefox → Load Temporary Add-on…

3

Select the downloaded marko-firefox.xpi file.

Temporary add-ons are removed on restart — reinstall after each browser restart.

4

Pin Marko to your toolbar, open any site, press Alt+M. Done.
